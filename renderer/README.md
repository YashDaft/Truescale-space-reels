# Renderer

Turns a storyboard and a fact sheet into a 1080×1920 video, using [Remotion](https://www.remotion.dev) and Three.js.

The renderer doesn't decide anything about content. It receives two JSON files and refuses to render if they break any rule.

## What it receives

**Fact sheet**: every number the reel may use.

```json
{
  "facts": {
    "jupiter_volume_ratio": {"value": 1321.33, "source": "https://nssdc.gsfc.nasa.gov/...", "level": "measured data"},
    "light_seconds": {"value": 499.005, "formula": "earth_sun_km / speed_of_light_km_s"}
  },
  "display": {
    "jupiter_volume_ratio": "1,321"
  }
}
```

`facts` holds raw values for drawing (sizes, distances, speeds). `display` holds the exact text for numbers in the reel's lines of text, so the wording of a number is decided once, in the fact sheet. Fact sheets are built and checked by the Python package in `factsheet/` at the top of the repo. Moving numbers inside a scene, like a counter running up or an orbit's lap count, are worked out by code from `facts` while they animate.

**Storyboard**: the style, the music, and the scenes in order. Each scene has its parameters, its lines of text (beats), and its sound effects, all timed in seconds from the start of the scene.

```json
{
  "scene": "volume_fill",
  "seconds": 10,
  "params": {"radius_ratio_fact": "jupiter_radius_ratio", "count_fact": "jupiter_volume_ratio"},
  "beats": [{"at": 7.7, "until": 10.0, "text": "{jupiter_volume_ratio} Earths!"}],
  "sounds": [{"at": 7.6, "file": "chime.wav"}]
}
```

See `examples/` for complete files.

## The rules it enforces

Before drawing anything, `src/validate.ts` checks the storyboard against `scene_catalog.json` and the fact sheet, and lists every problem at once:

- Text can't contain digits. Every number must be a `{placeholder}` that exists in the fact sheet's `display`.
- Every scene must exist in the catalog, belong to the reel's style, and fit the catalog's length limits.
- Every parameter must be known, of the right type, and point at facts that exist.
- Music must belong to the style, and sound effects must be in the catalog.

`tests/check_validator.sh` proves this on every pull request by trying to render a storyboard with planted mistakes.

## How it's organised

```text
scene_catalog.json    what each scene and style is, and the rules for its parameters
                      (the storyboard agent will read this to know what it can use)
src/
  Root.tsx            registers the videos; checks the storyboard before rendering
  Reel.tsx            plays the scenes in order with text, sounds, music and overlay
  validate.ts         the rules above
  facts.tsx           gives scenes the fact sheet; fills {placeholders}
  types.ts            the shapes of the JSON files
  scenes/             what is drawn: light_journey, volume_fill, orbit_clock
  styles/             how text looks and moves, plus overlays: cinematic, flat, line
  Planets.tsx         3D Earth and Sun
  loadFonts.ts        fonts, loaded before the first frame
examples/             example fact sheet (built by make_example_fact_sheet.py) and one storyboard per style
scripts/make_assets.py  makes the sound effects and the Sun texture with code
```

A **scene** decides what is drawn. A **style** decides how text looks and moves. This split is so new styles can be added without rewriting scenes.

## Running it

You need Node.js 22 or newer.

```bash
cd renderer
npm install
npm run studio                                         # preview in the browser
npx remotion render src/index.ts ExampleFlat out/flat.mp4
npx remotion render src/index.ts Reel out/reel.mp4 --props=path/to/input.json
```

`--props` takes a file with `{"storyboard": ..., "factSheet": ...}`. On a machine without a GPU, add `--gl=swangle`.
